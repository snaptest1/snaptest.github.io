SAWAAL

Aam sawaal

Kya ye app safe hai?

APK seedha hamare official GitHub release se aata hai. Android pehli baar chetavani dikha sakta hai kyunki app Play Store ke bahar se aa raha hai. Data ke baare mein Privacy page dekhein.

iPhone par kaise chalayein?

APK sirf Android ke liye hai. iPhone par "Web par kholein" dabayein, phir Safari mein Share menu se "Add to Home Screen" chunein.

Mera institute list mein nahi dikha?

Ho sakta hai aapke institute ka APK abhi bana na ho. Apne institute se poochhein. Tab tak Web par kholein se bhi sab kaam chalta hai.

Join code kahan se milega?

Join code aapke institute ke admin ya teacher dete hain.

Apne coaching ka app banwana hai?

Logo, naam aur rang dene par 10-15 minute mein aapka APK ban jaata hai.
